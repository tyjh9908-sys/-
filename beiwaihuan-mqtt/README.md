# 北外環 MQTT 平日排隊時長分析

此目錄為靜態網頁，沿用本儲存庫既有的 GitHub Pages 發布設定。

## 主要結果

- 最差兩天：2026-10-13、2026-09-30；平均 18.1794 分鐘／日／偵測區。
- 最佳三個一般平日：2026-09-18、2026-09-17、2026-10-01；平均 12.9041 分鐘／日／偵測區。
- 排隊至少3輛的時長平均差 5.2753 分鐘，約5分17秒（29.0%）。

最佳日期不全晚於最差日期；此為依結果挑選的情境差距，不能認定為實際措施啟用前後的因果成效。分鐘數不是每位駕駛節省的旅行時間。

## 網頁

GitHub Pages 部署成功後，此子頁路徑為 `/beiwaihuan-mqtt/`，原有儲存庫首頁保留不變。

網頁含排隊門檻切換、29個一般平日的每日資料、各區差異、計算方式及JSON下載，不需額外安裝套件。

## 本機預覽

在儲存庫根目錄執行 `python -m http.server 8000`，開啟 http://localhost:8000/beiwaihuan-mqtt/ 。

## 檔案

- index.html：版面與互動。
- data.json：29個一般平日及9個偵測區的彙整資料。

此目錄不含原始 MQTT 日誌或來源服務憑證。
