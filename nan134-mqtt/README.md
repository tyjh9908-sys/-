## 方法與限制

- 各區資料涵蓋率至少95%；最差／最佳都限一般平日，排除週末及9/25、9/28假日。
- 依實際事件時間轉為臺灣時間，連續回報間隔0–3秒才計入，較長間隔列為缺測；檔案間不外推。跨小時的有效間隔按邊界拆分，以精確區分07–09與17–19。
- 有效觀測時間加權的排隊占比乘該時段長度，全天1440分鐘、晨昏峰各120分鐘。
- 不代表個別駕駛旅行時間或措施因果成效；是依結果選取極端日期的情境比較。
- 欠缺資料日：2026-08-26、2026-09-08、2026-09-10；無來源日：2026-09-09。
- 設備名稱以Excel建構工作表A2:C14的StreamID精確對照；不推定zone等於特定行車方向。
- 解析錯誤0筆、重複或非遞增回報0筆；快速欄位抽取與完整JSON解析進行逐檔抽樣核對。
